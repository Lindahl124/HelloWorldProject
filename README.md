HelloWorldProject är ett enkelt fullstack-projekt bestående av en frontend byggd med React och en backend skapad med .NET 8.

Teknologier:

- Frontend: React
- Backend: .NET 8 (ASP.NET Core Web API)

Funktionalitet:

- En backend-API som hanterar en enkel "Hello World"-endpoint.
- En frontend som anropar backend och visar svaret i webbläsaren.
- CORS-konfiguration för att tillåta frontend att kommunicera med backend.
